## Schema

Schema: eventCode, stormCode, eventLength, County, ohLine, sumAFWA_TOTPRECIP, peakWSPD10, wgt5, wgt9, wgt13, wgt18, outage.

### Column notes

- **outage:** (trouble spots counted and sent crew to) (not exact data)

- **ohLine:**  over head power line length for the county (not real data) (meters or feet)

- **wgt():** num of hours where  winds speed above ()meters/second

- **peakWSPD10:** wind speed peak hours

- **sumAFWA_TOTPRECIP:** precipitation during storm (mm)
